# AI-Powered English Learning Platform - Frontend

This is the frontend part of the AI-Powered English Learning Platform for children, designed to provide an interactive and engaging learning experience. The frontend is built using React.js and is structured to facilitate collaboration among multiple developers.

## Project Structure

- **public/**: Contains static files such as the main HTML file.
- **src/**: Contains the source code for the React application.
  - **components/**: Reusable components for various features.
  - **pages/**: Different pages of the application.
  - **App.jsx**: The main application component that integrates all components.
  - **index.js**: The entry point for the React application.

## Getting Started

To get started with the frontend development, follow these steps:

1. **Clone the Repository**
   ```
   git clone <repository-url>
   cd ai-english-learning-platform/frontend
   ```

2. **Install Dependencies**
   Make sure you have Node.js installed. Then run:
   ```
   npm install
   ```

3. **Run the Application**
   Start the development server:
   ```
   npm start
   ```

4. **Build for Production**
   To create a production build, run:
   ```
   npm run build
   ```
